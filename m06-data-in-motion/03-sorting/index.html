Сортировка с пропусками

Открой app.js и консоль. Данные уже отображаются; сортировку ты пишешь сам в свободной области файла.

  1. Напиши sortRecords(records, mode). Каждый вызов возвращает новый массив, не меняя входные данные. Допустимые режимы: "score", "name", "date", "original".
  2. В режиме score сортируй числа по убыванию; в name — названия по возрастанию. Для строк используй localeCompare с локалью "en"; в данных названия на английском.
  3. В режиме date сортируй строки ISO YYYY-MM-DD от новых к старым. Записи с date: null должны идти последними.
  4. При равенстве основного значения в любом из трёх режимов сортируй по числовому id по возрастанию. Это относится и к двум отсутствующим датам. Напиши функцию сортировки, которая возвращает отрицательное число, ноль или положительное число.
  5. Для восстановления порядка вызови режим original с сохранённым исходным массивом RECORDS, а не с отсортированным результатом: верни его копию. Это не сортировка по id.
  6. Выведи полученные массивы id через report("Подпись", значение). Переключи все режимы по очереди, затем восстанови исходный порядок. Проверь, что исходный массив и его объекты не изменились.

Ожидаемые id по порядку

  • score: [1, 2, 4, 5, 3, 6].
  • name: [6, 1, 2, 4, 3, 5].
  • date: [1, 4, 6, 3, 2, 5].
  • original: [4, 2, 6, 1, 5, 3].
  • Для пустого входа каждый режим возвращает новый []. Оценка 0 — число, не пропуск. Все остальные даты корректны; разбирать их через Date не требуется.
