Метки из записей

Открой app.js и консоль. Отображение данных уже работает; обработку ты пишешь сам в свободной области файла.

  1. Напиши collectLabels(records). Через flatMap собери все метки в один массив flattened, сохранив порядок и повторы.
  2. Получи массив unique: убери повторы через Set и отсортируй метки по возрастанию.
  3. Через reduce посчитай frequencies — объект, где ключ — метка, значение — число появлений. Верни { flattened, unique, frequencies }.
  4. Передай реальные результаты в report("Подпись", значение). Проверь пустой вход и сравни исходные записи и их tags до и после: они не должны меняться.

Что должно получиться

  • flattened: ["red", "blue", "red"].
  • unique: ["blue", "red"].
  • frequencies: { blue: 1, red: 2 }. Порядок ключей объекта не важен.
  • Для []: { flattened: [], unique: [], frequencies: {} }. Запись с tags: [] не добавляет ни метки, ни счётчика.
  • У каждой записи есть массив tags. Метки — строки; регистр значим, приведение к нижнему регистру не требуется.
