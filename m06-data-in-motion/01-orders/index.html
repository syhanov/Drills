Заказы

Открой app.js и консоль браузера. Данные и вывод на странице уже работают; расчёт ты пишешь сам в свободной области файла.

  1. Напиши summarizeOrders(orders). Через filter оставь оплаченные заказы, через map получи суммы price * quantity, через reduce сложи их. Верни объект { paidIds, lineTotals, total }; оба массива идут в порядке исходных оплаченных заказов.
  2. Напиши totalPaidWithLoop(orders): тот же итог обычным циклом, без методов обработки массивов. Сравни оба результата.
  3. Выведи реальные результаты через report("Подпись", значение). Проверь исходный массив до и после вызовов: его порядок и все поля должны сохраниться.

Что должно получиться

  • paidIds: [1, 2, 4, 6], lineTotals: [240, 225, 0, 60], total: 525. Цикл тоже возвращает 525.
  • Для [] и массива только неоплаченных заказов: { paidIds: [], lineTotals: [], total: 0 }; цикл возвращает 0.
  • Оплаченный заказ с нулевой ценой остаётся в выборке; неоплаченный заказ за 10000 не входит в итог. Данные корректные: числа неотрицательные, количество целое, paid — boolean.
